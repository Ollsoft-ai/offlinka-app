# iOS: what has not been compiled or tested

Written on Linux. **Checked here:** every file parses; the Foundation-only layer (scanner, URL scheme, responder, search model, store, catalog, L10n, fake source, core adapter) type-checks in Swift 5 and 6 modes and its unit tests pass, including the adapter against the real core and real ZIMs. **Not checked:** anything that imports SwiftUI, UIKit or WebKit, the Xcode project, signing, devices. Ranked by risk; the first five decide whether the app works at all.

## High

1. **Unplugging during a search can crash (core).** The core memory-maps `.offidx` files from the drive (`memmap2` in `core/src/index.rs`). If the drive goes away while an index page is not resident, the next search touches the mapping and the process gets SIGBUS. The app releases the books within 2 s of losing the drive, but a search in that window crashes. Fix belongs in the core (read the index into memory, or `pread` it). Also unknown: whether `mmap` works at all on files of the iOS external-drive file provider (the core falls back to reading when `mmap` fails, but not when the first access fails).
2. **Security-scoped access to the USB drive.** Assumes `.fileImporter(allowedContentTypes: [.folder])` returns the drive root, `startAccessingSecurityScopedResource()` on that folder lets the Rust core `open()`/`pread()` files below it by POSIX path for the whole session, and `bookmarkData(options: [])` resolves again after the drive is unplugged and plugged back (`DriveAccess`). If replugging gives a stale or unresolvable bookmark, the unplugged screen offers "Vybrat jinou flashku"; nothing else depends on it.
3. **Linking the core.** Assumes `scripts/build-ios-core.sh` yields `ios/Frameworks/OfflinkaCore.xcframework` whose `Headers/module.modulemap` defines `offlinka_coreFFI`, and that the generated `Generated/OfflinkaCore.swift` (`import offlinka_coreFFI` behind `#if canImport`) compiles inside the app module. Rust std may need extra system libraries at link time: if there are undefined symbols, run `cargo rustc --release --lib -p offlinka-core --target aarch64-apple-ios --crate-type staticlib -- --print native-static-libs` and add them to `OTHER_LDFLAGS` in `project.yml`.
4. **WKURLSchemeHandler behaviour.** Assumes: custom-scheme pages get a real origin per host (`offlinka://wikipedia_cs_all`), so `localStorage` works for games and `fetch`/XHR to the same scheme works (Capacitor relies on this); `206` replies with `Content-Range` play `<video>`/`<audio>`; `Range` arrives in `allHTTPHeaderFields`; requests from Web Workers (MapLibre in the maps ZIM) also reach the handler; hosts with `_` (`wikipedia_cs_all`) are accepted and come back unchanged (they are lowercased on our side anyway). ZIM redirects are answered with a tiny page that calls `location.replace` (WKURLSchemeHandler has no public redirect API). Test on device: maps ZIM pans and zooms, a game keeps its score, a PDF in the guides opens.
5. **SwiftUI/WebKit code never compiled.** Expect a handful of compile errors. Most likely spots: `@Bindable var router = app.router` inside `MainTabsView.body`; `.toolbarBackground(_, for: .navigationBar, .bottomBar)`; `.brandText(...)` (Brand.swift) applied to a `Button`; `ToolbarItemGroup(placement: .bottomBar)` with `Spacer()`s; `.alert(_:isPresented:presenting:actions:message:)` with a `URL`; `Label { } icon: { }` inside `ChipButtonStyle`; `List`/`Section` builders with local `let`s.

## Medium

6. **WebKit delegates and actor isolation.** `ReaderWebCoordinator` and `OfflinkaSchemeHandler` are plain `NSObject` classes; every delegate method wraps its body in `MainActor.assumeIsolated` so it compiles whether or not the SDK marks the protocols `@MainActor`. Risk: `decidePolicyFor … decisionHandler: @escaping (WKNavigationActionPolicy) -> Void` being reported as "nearly matches" (then it is never called and external links fall through to the content rules, which still block them). Watch the build warnings.
7. **Offline content rules.** `WKContentRuleListStore.default().compileContentRuleList(forIdentifier:encodedContentRuleList:)` (async variant) compiles `^https?:`, `^wss?:`, `^ftp:` block rules. If the async variant has a different return type, use the completion-handler form. Check with the Network instrument that the reader makes no connection.
8. **Strings.** `tr()` loads `cs/sk/en.lproj` compiled from design's `Localizable.xcstrings` and formats plurals with `String(format:locale:arguments:)` on the string returned by `Bundle.localizedString` (stringsdict-style plural variations). `LocalizationTests` checks every key in all three languages and the plurals. In-app language switch rebuilds the root view (`.id(language)`); open readers reload on the same page.
9. **Reader stylesheet.** Design's `design/reader/offlinka-reader.css` and `inject.js` are referenced as optional resources (`project.yml`) and served at `/_offlinka/reader.css`, `/_offlinka/inject.js`, `/_offlinka/fonts/*.ttf` on every book host; the `<link>`/`<script>` are inserted before `</head>` of Wikimedia pages only. If design renames or moves the files, update `project.yml` and `AppAssets.aliases`.
10. **Privacy manifest.** Declares only File timestamp `3B52.1` (the core's `fstat` on the ZIMs the user picked). If `nm -u` on the app binary shows `mach_absolute_time` (Rust `Instant`), add System boot time `35F9.1`; `statfs` would need Disk space. Apple rejects uploads with undeclared required-reason APIs.
11. **Theme.** `ThemeApplier` sets `overrideUserInterfaceStyle` on every window (instead of `.preferredColorScheme`, which does not reliably return to "system"). Assumes WKWebView's `prefers-color-scheme` follows it; the reader also passes the theme explicitly to `inject.js`.
12. **Drive monitoring.** Every 2 s while reading: `FileManager.fileExists` on the drive root (main thread). Assumes this returns quickly on a vanished volume and never blocks. Read errors from the scheme handler trigger an immediate check, and a reopen when the drive is still there (replugged between checks).
13. **Icons.** `UIImage(named:)` finds design's SVG imagesets (`preserves-vector-representation`, template) in the second asset catalog; SF Symbols are drawn otherwise. Tab bar icons are SF Symbols for now.
14. **Fonts.** `UIAppFonts` lists design's four TTFs; Brand.swift uses PostScript names `Archivo-Regular`, `Archivo-SemiBold`, `Archivo-Bold`, `ArchivoExpanded-ExtraBold`.

## Low

15. **iPad.** Same tab layout as the phone, grids widen with `.adaptive`; one window only (`UIApplicationSupportsMultipleScenes: false`). Untested in split view.
16. **Find in page** uses `isFindInteractionEnabled` + `findInteraction?.presentFindNavigator(showingReplace: false)`.
17. **Performance.** Main page under 2 s and suggestions under 100 ms per keystroke depend on `pread` speed over the external exFAT file provider; measured only on Linux.
18. **UI tests.** `SmokeUITests` relies on accessibility identifiers and Czech labels on the demo drive; web content is queried through `app.webViews`.
19. **XcodeGen details.** `excludes` with folder names, `optional: true` sources, `type: folder` for test fixtures, `${OFFLINKA_TEAM_ID}` in `DEVELOPMENT_TEAM`, `xcodeVersion`.
20. **fastlane.** Lanes were not run (no Ruby here). `increment_build_number` needs `VERSIONING_SYSTEM = apple-generic` (set).
