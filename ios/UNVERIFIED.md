# iOS: what has not been compiled or tested

Written on Linux. **Checked here** (Swift 6.4.3 Linux toolchain): every file parses; the whole app, the generated bindings and `design/out/ios/Brand.swift` type-check in Swift 5 and Swift 6 language modes against **hand-written stand-ins for SwiftUI, UIKit, WebKit and UniformTypeIdentifiers** (they prove the app is consistent with itself and with the API as I believe it to be, not that Apple's signatures match); the Foundation-only layer runs its unit tests, including `CoreContentSourceTests` against the real core built from `main` on the real guides ZIM. **Not checked:** real Apple SDKs, the Xcode project, asset and string catalog compilation, signing, simulators, devices. Ranked by risk; the first four decide whether the app works at all.

## High

1. **Security-scoped access to the USB drive.** Assumes `.fileImporter(allowedContentTypes: [.folder])` returns the drive root, `startAccessingSecurityScopedResource()` on that folder lets the Rust core `open()`/`pread()` files below it by POSIX path for the whole session, and `bookmarkData(options: [])` resolves again after the drive is unplugged and plugged back (`DriveAccess`). If replugging gives a stale or unresolvable bookmark, the unplugged screen offers „Vybrat jinou flashku“; nothing else depends on it.
2. **Linking the core.** Assumes `scripts/build-ios-core.sh` yields `ios/Frameworks/OfflinkaCore.xcframework` whose `Headers/module.modulemap` defines `offlinka_coreFFI`, and that `Generated/OfflinkaCore.swift` compiles inside the app module (`project.yml` excludes the generated `.h` and `.modulemap` from the target; they ship in the XCFramework). Since core `0527742` the static library also contains C `libzstd` (compiled by `zstd-sys` through the `cc` crate, which needs the Xcode command line tools and finds the iOS SDK with `xcrun`). Rust std may need extra system libraries at link time: if there are undefined symbols, run `cargo rustc --release --lib -p offlinka-core --target aarch64-apple-ios --crate-type staticlib -- --print native-static-libs` and add them to `OTHER_LDFLAGS` in `project.yml`.
3. **WKURLSchemeHandler behaviour.** Assumes: custom-scheme pages get a real origin per host (`offlinka://wikipedia_cs_all`), so `localStorage` works for games and `fetch`/XHR to the same scheme works (Capacitor relies on this); `206` replies with `Content-Range` play `<video>`/`<audio>`; `Range` arrives in `allHTTPHeaderFields`; requests from Web Workers (MapLibre in the maps ZIM) also reach the handler; hosts with `_` are accepted. ZIM redirects are answered with a tiny page that calls `location.replace` (no public redirect API). Test on a device: maps pan and zoom, a game keeps its score, a guide PDF opens.
4. **Real SDK signatures.** Most likely compile errors on the first Xcode build, all in view code: `@Bindable var router = app.router` inside a `body`; `.toolbarBackground(_, for: …)` with several bars; `.brandText(...)` (Brand.swift, uses `tracking`/`lineSpacing` on `some View`) applied to `Button`s; `ToolbarItem(placement: .topBarLeading)` holding an `HStack`; `.alert(_:isPresented:presenting:actions:message:)`; `Slider(value:in:step:)` with a `Double` binding; `Label(_:image:)` in tab items; `List`/`Section` builders with local `let`s. Expect minutes of fixes, not redesign.

## Medium

5. **WebKit delegates and actor isolation.** `ReaderWebCoordinator` and `OfflinkaSchemeHandler` are plain `NSObject` classes; every delegate method wraps its body in `MainActor.assumeIsolated`, so it compiles whether or not the SDK marks the protocols `@MainActor`. Watch for a "nearly matches optional requirement" warning on `decidePolicyFor … decisionHandler:`: if it appears the method is never called (external links would then only be blocked by the content rules, without the notice).
6. **Offline content rules.** The async `WKContentRuleListStore.compileContentRuleList(forIdentifier:encodedContentRuleList:)` compiles `^https?:`, `^wss?:`, `^ftp:` block rules. Check with the Network instrument that the reader makes no connection.
7. **Strings.** `tr()` loads the `cs/sk/en.lproj` Xcode compiles from design's `Localizable.xcstrings` and formats plurals with `String(format:locale:arguments:)` on the string `Bundle.localizedString` returns. `LocalizationTests` (skipped on Linux) checks every key in all three languages and the plurals. Language switch in Settings rebuilds the root view; open readers come back on the same page.
8. **Reader stylesheet hook.** Design's `design/reader/offlinka-reader.css` and `inject.js` are bundled and served at `/_offlinka/reader.css`, `/_offlinka/inject.js`, `/_offlinka/fonts/*.ttf` on every book host; the `<script>window.__offlinka=…</script><link …><script src=…>` snippet goes before `</head>` of Wikimedia HTML only (unit-tested). Live changes call `offlinkaReader({theme, scale})`. Text sizes are 0.8 … 1.6.
9. **Privacy manifest.** Declares only File timestamp `3B52.1` (the core's `fstat` on the ZIMs the user picked). If `nm -u` on the app binary shows `mach_absolute_time` (Rust `Instant`), add System boot time `35F9.1`; `statfs` would need Disk space. Apple rejects uploads with undeclared required-reason APIs.
10. **Theme.** `ThemeApplier` sets `overrideUserInterfaceStyle` on every window (instead of `.preferredColorScheme`, which does not reliably return to "system"). Assumes WKWebView's `prefers-color-scheme` follows it; the reader also passes the theme to `inject.js`.
11. **Drive monitoring.** Every 2 s while reading: `FileManager.fileExists` on the drive root (main thread). Assumes it returns quickly on a vanished volume. Read errors from the scheme handler trigger an immediate check, and a reopen when the drive is still there (replugged between checks). The core reads the search index with `pread` since `b177e23`, so an unplug during a search is an I/O error, not a crash.
12. **Icons and fonts.** Design's SVG imagesets (`Icons.xcassets`, template) are found by `UIImage(named:)` / `Image(_:)`; SF Symbols are the fallback. `UIAppFonts` lists design's four TTFs (PostScript names in Brand.swift). The app icon set is a copy made by `tools/sync-design.sh`.
13. **Reader top bar.** The book name switches to the article title once the page scrolled 72 pt (KVO on `scrollView.contentOffset`), a simplification of design's "when the h1 is under the bar".

## Low

14. **iPad.** Same tab layout as the phone, tiles widen; one window (`UIApplicationSupportsMultipleScenes: false`). Untested in split view.
15. **Find in page** uses the system find bar (`isFindInteractionEnabled`, `presentFindNavigator(showingReplace:)`), not design's custom find bar (the README allows native find).
16. **Performance.** Main page under 2 s and suggestions under 100 ms per keystroke depend on `pread` over the external exFAT file provider; measured only on Linux.
17. **UI tests.** `SmokeUITests` relies on accessibility identifiers and Czech labels on the demo drive; web content is queried through `app.webViews`.
18. **XcodeGen details.** `excludes` with folder names, `optional: true` sources, `type: folder` for test fixtures, `${OFFLINKA_TEAM_ID}` in `DEVELOPMENT_TEAM`.
19. **fastlane.** Lanes were not run (no Ruby here). `increment_build_number` needs `VERSIONING_SYSTEM = apple-generic` (set). Store texts are a draft until `store/` has the shared listing.
